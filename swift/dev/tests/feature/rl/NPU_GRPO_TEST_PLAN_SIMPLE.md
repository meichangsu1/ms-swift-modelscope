执行约定：

- 同步模式分为同步和异步：同步使用 `async_mode=none`，异步统一使用 `async_mode=fully_async`，通过独立的 `max_staleness` 列覆盖窗口大小 `1` 和 `4`。异步＋`in_place` 按现有约束设置 `allow_partial_rollout=true`；`adapter_snapshot` 设置 `allow_partial_rollout=false`。统一 `parameter_sync_step=1`、`dynamic_batching=false`。
- colocate 共享训练卡；disaggregated 的总卡数为训练卡数加采样 TP 卡数，再加独立辅助模型所需卡数。colocate 统一使用 `sleep_level=1`、`offload_model=true`、`offload_optimizer=true`。R07 使用 `per_device_train_batch_size=1`、`max_length=1024`、`max_completion_length=512`；30B 模型的 FP32 全参训练在 8 张约 61 GiB 的 NPU 上仍需确认峰值显存，阶段切换 offload 不等于训练期间的 CPU 参数 / 优化器 offload。
- R06 / R07 必须显式启用专家并行。R06 使用 `parallel_spec=fsdp4ep2epfsdp2`、`model_kwargs={"fsdp_config":{"expert_parallel":{"enabled":true,"ep_size":2}}}`、`target_parameters=["mlp.experts.gate_up_proj","mlp.experts.down_proj"]` 和 `lora_dropout=0.0`；R07 使用 `parallel_spec=fsdp8ep8epfsdp1`，并将 `model_kwargs` 中的 `ep_size` 改为 `8`。
- R08 是预留的功能覆盖项，设置 `sequence_parallel_size=2`。当前 `_check_sp_hf_feasibility()` 会拒绝 FSDP＋Ulysses SP；在支持该组合之前，不能将校验报错或退化为 SP=1 记作该项通过。
- R04 / R05 的 HCCL 全量权重同步使用原生 torch-npu 通信组，执行前先在目标环境验证双 NPU 通信。R03 的增量传输仅配置在 vLLM 分离部署路径；R06 的 adapter 快照通过路径发布，不使用权重传输后端。
